## Usage

```bash
demo-cli-clean --verbose
demo-cli-clean --dry-run
demo-cli-clean --help
demo-cli-clean --version
```

| Flag | Description |
| --- | --- |
| `--verbose` | Verbose logging |
| `--dry-run` | Print actions without writing |
| `--help` | Show help |
| `--version` | Print version |
